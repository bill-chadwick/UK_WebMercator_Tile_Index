# UK_WebMercator_Tile_Index
Set of bit maps for zooms 6 to 15 that show where there are useful web mercator map tiles. These might be useful for creating UK wide tile archives that avoid too much sea. 

Each filename includes its minimum and maximum x and y coordinates

The indexes include Scilly, St Kilda, Shetland and the Isle of Man, though the Isle Of Man is excluded in zoom 15.
